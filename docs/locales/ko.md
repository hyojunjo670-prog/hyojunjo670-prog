> "기계적 공감(Mechanical Sympathy), 결정론적 지연 시간, 철저한 자원 효율성."

하드웨어의 한계에 도전하며 오버헤드를 극한으로 줄인 시스템 및 분산 인프라 소프트웨어를 연구·개발합니다. 찰나의 마이크로초와 CPU 캐시 라인 하나까지 고려하여, 초저지연 데이터 파이프라인, 락프리 동시성 알고리즘, 리눅스 커널 서브시스템(`eBPF` / `io_uring`), 임베디드 스토리지 엔진을 직접 설계하고 구현합니다.

---

## 🧭 엔지니어링 철학

- **기계적 공감(Mechanical Sympathy)**: L1/L2/L3 CPU 캐시 라인, TLB 히트율, NUMA 메모리 노드 토폴로지, 분기 예측기(Branch Predictor) 등 물리 하드웨어의 동작 원리를 깊이 이해하고 조화롭게 동작하는 코드를 지향합니다.
- **최고 처리량보다 예측 가능한 지연 시간(Tail Latency)**: 일시적인 평균 처리량의 숫자보다 극한의 부하 상황에서도 99.9 백분위수(p99.9) 지연 시간이 튀지 않는 결정론적 안정성을 최우선 가치로 둡니다.
- **무할당(Zero-Allocation) 핫패스 설계**: 데이터가 흐르는 핵심 루프(Hot Loop)에서는 불필요한 동적 메모리 할당, 동적 디스패치 오버헤드, 잦은 시스템 콜 컨텍스트 스위칭을 원천 차단합니다.
- **외부 의존성 최소화**: 보안 취약점과 라이브러리 비대화를 유발하는 거대한 의존성 트리 대신, 견고하고 투명한 POSIX 및 언어 표준 라이브러리를 기반으로 자립형 시스템을 구축합니다.

## 🚀 주요 오픈소스 프로젝트

### 1. `pulse-ring` — 초고성능 락프리 링버퍼
- **사용 언어**: Rust
- **프로젝트 개요**: 마이크로초 미만의 이벤트 전송을 위해 캐시 라인 패딩과 원자적 메모리 순서(`Acquire` / `Release`)를 적용한 유계 단일 생산자-다중 소비자(SPMC) 및 다중 생산자-다중 소비자(MPMC) 순환 버퍼.
- **핵심 특징**:
  - 데이터 전송 중 동적 메모리 할당 0건; 뮤텍스 락 경합 없이 순수 원자적 연산으로 동작.
  - 최신 x86_64 AVX-512 머신에서 초당 4,800만 개 이상의 메시지 전송 처리량 기록.

### 2. `aether-kv` — 임베디드 LSM-Tree 키-값 저장소
- **사용 언어**: C++20 / C
- **프로젝트 개요**: NVMe SSD 환경에 최적화하여 리눅스 `io_uring` 비동기 배치 다이렉트 I/O(`O_DIRECT`) 기반으로 설계된 초고속 임베디드 스토리지 엔진.
- **핵심 특징**:
  - CRC32 체크섬을 탑재한 세그먼트 WAL(Write-Ahead Log)로 시스템 비정상 종료 시 무손실 복구 보장.
  - 2계층 티어드 컴팩션으로 쓰기 증폭(Write Amplification)을 최소화하면서 읽기 p99 지연 시간 120마이크로초 이하 유지.

### 3. `packet-lens` — 커널 스페이스 eBPF 플로우 텔레메트리 프로브 (Probe)
- **사용 언어**: C / Go
- **프로젝트 개요**: 리눅스 커널 eBPF XDP/TC 훅에 직접 연결되어 패킷 복사 없이 TCP 왕복 시간(RTT), 패킷 손실, 재전송 상태를 제로 오버헤드로 추적하는 관측성 데몬.
- **핵심 특징**:
  - 사용자 공간으로 원시 패킷을 복사하지 않고 커널 내부 링버퍼를 통해 메트릭만 초고속 추출.
  - 밀리초 미만의 네트워크 지연 악화를 선제 감지하여 전송하는 프로메테우스 익스포터 내장.

### 4. `flow-rpc` — 제로 카피 바이너리 RPC 프레임워크
- **사용 언어**: Rust / Go
- **프로젝트 개요**: Unix Domain Socket 및 초고속 TCP 환경에서 JSON/Protobuf의 역직렬화 병목을 제거하기 위해 설계된 미니멀 바이너리 RPC 프레임워크.
- **핵심 특징**:
  - FlatBuffers 스키마 검증을 기반으로 수신 버퍼에서 추가 복사 없이 메모리 직접 매핑.
  - 워커 코어당 최대 100,000개의 동시 영구 커넥션을 처리하는 경량 멀티플렉싱 엔진 탑재.
