> 「メカニカル・シンパシー（ハードウェア共感）、決定論的レイテンシ、徹底したリソース効率。」

ハードウェアの極限性能を引き出し、オーバーヘッドを最小化したシステムソフトウェアおよび分散インフラを研究・開発しています。マイクロ秒単位の応答速度とCPUキャッシュラインの境界を意識し、超低レイテンシデータパイプライン、ロックフリー並行処理アルゴリズム、Linuxカーネルサブシステム（`eBPF` / `io_uring`）、組み込み型ストレージエンジンを直接設計・構築しています。

## 🧭 エンジニアリング哲学

- **メカニカル・シンパシー（Mechanical Sympathy）**: L1/L2/L3 CPUキャッシュライン、TLBヒット率、NUMAメモリートポロジー、分岐予測器など、物理ハードウェアの動作原理を深く理解し調和するソフトウェアを構築します。
- **最大スループットより予測可能なレイテンシ**: 一時的な平均スループットの数値よりも、高負荷下でも99.9パーセンタイル（p99.9）レイテンシが跳ね上がらない決定論的な安定性を最重視します。
- **ゼロアロケーション（Zero-Allocation）ホットパス**: データが流れるクリティカルなループ内では、動的メモリ確保、動的ディスパッチ、頻繁なシステムコールのコンテキストスイッチを徹底的に排除します。
- **外部依存の極小化**: 肥大化や脆弱性の温床となる巨大な依存ツリーを避け、堅牢で透明性の高いPOSIXおよび言語標準ライブラリを基盤とします。

## 🚀 主要オープンソースプロジェクト

### 1. `pulse-ring` — 超高速ロックフリーリングバッファ
- **使用言語**: Rust
- **概要**: マイクロ秒未満のイベント伝送を実現するため、キャッシュラインパディングと不可分操作順序（`Acquire` / `Release`）を適用した有界単一プロデューサー・複数コンシューマー（SPMC）および複数プロデューサー・複数コンシューマー（MPMC）循環バッファ。
- **主な特徴**:
  - 送信時の動的メモリ確保ゼロ。ミューテックス競合なしのアトミック操作のみで動作。
  - 最新のx86_64 AVX-512環境で毎秒4,800万メッセージ以上のスループットを記録。

### 2. `aether-kv` — 組み込み型LSM-Tree Key-Valueストレージ
- **使用言語**: C++20 / C
- **概要**: NVMe SSD向けに最適化され、Linux `io_uring`の非同期バッチダイレクトI/O（`O_DIRECT`）を活用した高速組み込み型キーバリューストレージエンジン。
- **主な特徴**:
  - CRC32チェックサム付きセグメント化WAL（Write-Ahead Log）による耐障害性とクラッシュ後の一貫性を保証。
  - 2階層ティアードコンパクションにより書き込み増幅（Write Amplification）を抑え、読み取りp99レイテンシ120マイクロ秒以下を維持。

### 3. `packet-lens` — カーネル空間eBPFフローテレメトリエージェント
- **使用言語**: C / Go
- **概要**: LinuxカーネルのeBPF XDP/TCフックに直結し、パケットをコピーすることなくTCPラウンドトリップ時間（RTT）、パケットロス、再送状態を低オーバーヘッドで追跡する監視デーモン。
- **主な特徴**:
  - ユーザ空間への生パケットコピーを排除し、カーネル内リングバッファを通じてメトリクスのみを高速抽出。
  - サブミリ秒単位のネットワーク劣化アラートを出力するPrometheus Exporter内蔵。

### 4. `flow-rpc` — ゼロコピーバイナリRPCフレームワーク
- **使用言語**: Rust / Go
- **概要**: Unixドメインソケットおよび高速TCP環境におけるJSON/Protobufのデシリアライズボトルネックを解消するために設計されたミニマルバイナリRPCフレームワーク。
- **主な特徴**:
  - FlatBuffersスキーマ検証によるメモリバッファの直接マッピング（ゼロコピー）。
  - ワーカーコアあたり最大10万件の同時持続接続を維持する高効率多重化エンジンを搭載。
