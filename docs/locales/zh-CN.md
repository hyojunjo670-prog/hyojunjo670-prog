## 🧭 工程哲学

- **机械同理心（Mechanical Sympathy）**：深入理解并顺应硬件底层运行机制——L1/L2/L3 缓存行对齐、TLB 命中率、NUMA 拓扑架构以及分支预测逻辑。
- **确定性延迟胜于瞬时峰值吞吐**：相比短暂的高平均吞吐量，系统在极端负载下仍能保持平稳、无抖动的第 99.9 百分位数（p99.9）延迟具有更高的工程价值。
- **核心热路径零动态内存分配（Zero-Allocation）**：高频数据路径中杜绝一切不必要的内存分配、动态分发（Dynamic Dispatch）以及多余的系统调用上下文切换。
- **克制外部依赖**：避免过度依赖臃肿脆弱的三方依赖树，优先立足于坚实、透明的 POSIX 标准及语言标准库构建稳健的自立系统。

## 🚀 重点开源项目

### 1. `pulse-ring` — 超高吞吐量无锁环形缓冲区
- **开发语言**：Rust
- **项目概述**：专为亚微秒级事件分发设计，具备 CPU 缓存行填充（Padding）与原子内存顺序（`Acquire` / `Release`）的有界单生产者多消费者（SPMC）及多生产者多消费者（MPMC）循环队列。
- **技术亮点**：
  - 数据传输全程零动态内存分配；基于原子指令实现，完全消除互斥锁争用。
  - 在现代 x86_64 AVX-512 硬件环境下实测达到超过 4800 万条/秒的消息传输吞吐量。

### 2. `aether-kv` — 嵌入式 LSM-Tree 键值存储引擎
- **开发语言**：C++20 / C
- **项目概述**：专为 NVMe SSD 架构优化，基于 Linux `io_uring` 异步批处理直接 I/O（`O_DIRECT`）构建的高性能嵌入式 Key-Value 引擎。
- **技术亮点**：
  - 带有 CRC32 校验的分段预写日志（WAL），确保系统异常宕机后的崩溃一致性与零数据损坏。
  - 两级分层压缩策略，在将写放大（Write Amplification）降至最低的同时，将读请求 p99 延迟稳定控制在 120 微秒以内。

### 3. `packet-lens` — 内核态 eBPF 网络流遥测代理
- **开发语言**：C / Go
- **项目概述**：直接挂载至 Linux 内核 eBPF XDP/TC 钩子，以极低 CPU 负载提取 TCP 往返时间（RTT）、丢包率及重传状态的轻量级可观测性守护进程。
- **技术亮点**：
  - 全程在内核态运行；通过内核环形缓冲区输出遥测指标，避免向用户空间进行原始数据包拷贝。
  - 内置 Prometheus 监控指标导出器，支持毫秒级网络性能恶化实时告警。

### 4. `flow-rpc` — 零拷贝二进制 RPC 传输框架
- **开发语言**：Rust / Go
- **项目概述**：旨在消除 Unix Domain Socket 及高速 TCP 网络中 JSON/Protobuf 反序列化瓶颈的极简高性能二进制 RPC 框架。
- **技术亮点**：
  - 基于 FlatBuffers 架构实现接收缓冲区直接内存映射与零内存复制。
  - 集成高效多路复用调度引擎，单工作核心（Worker Core）支持高达 100,000 个并发持久连接。
