> "मैकेनिकल सिम्पैथी, नियतात्मक विलंबता, और कठोर संसाधन दक्षता।"

मैं एक सिस्टम और वितरित अवसंरचना सॉफ्टवेयर इंजीनियर हूँ, जो न्यूनतम ओवरहेड और अत्यधिक कुशल सिस्टम बनाने के लिए समर्पित है। मेरा ध्यान निम्न-विलंबता डेटा पाइपलाइन, लॉक-मुक्त समवर्ती एल्गोरिदम, लिनक्स कर्नेल सबसिस्टम (`eBPF` / `io_uring`), और एम्बेडेड स्टोरेज इंजन पर केंद्रित है।

---

## 🧭 इंजीनियरिंग दर्शन

- **मैकेनिकल सिम्पैथी**: हार्डवेयर स्तर—L1/L2/L3 सीपीयू कैश लाइन, TLB हिट दर, NUMA आर्किटेक्चर, और ब्रांच प्रेडिक्शन के साथ पूर्ण सामंजस्य में सॉफ्टवेयर डिजाइन करना।
- **औसत थ्रूपुट से बेहतर पूर्वानुमेय विलंबता**: भारी लोड के तहत भी टेल-लेटेंसी (p99.9) को स्थिर और नियंत्रित रखना।
- **शून्य-मेमोरी आवंटन हॉट पाथ**: सिस्टम के महत्वपूर्ण लूप्स में अनावश्यक गतिशील मेमोरी आवंटन और सिस्टम कॉल संदर्भ स्विचिंग को रोकना।
- **न्यूनतम बाहरी निर्भरताएँ**: अत्यधिक निर्भरता के बजाय मजबूत और पारदर्शी POSIX और मानक पुस्तकालयों को प्राथमिकता देना।

| **C (C11 / GNU99)** | प्रोडक्शन स्तर | लिनक्स कर्नेल मॉड्यूल, eBPF प्रोग्राम, निम्न-स्तरीय POSIX सिस्टम |
| **C++ (C++20)** | उन्नत | लॉक-मुक्त डेटा संरचनाएं, SIMD वेक्टर गणना, स्टोरेज इंजन |
| **Go** | उन्नत | वितरित नियंत्रण तल, RPC माइक्रो-डेमन, नेटवर्किंग सेवाएं |
| **POSIX Shell / Bash** | कुशल | स्वचालित परिनियोजन, कर्नेल निर्माण पाइपलाइन, CI वर्कफ़्लो |

## 🚀 प्रमुख ओपन-सोर्स परियोजनाएं

### 1. `pulse-ring` — उच्च-थ्रूपुट लॉक-मुक्त रिंग बफर
- **भाषा**: Rust
- **विवरण**: उप-माइक्रोसेकंड ईवेंट वितरण के लिए डिज़ाइन किया गया कैश-लाइन पैडेड SPMC/MPMC बफर।

### 2. `aether-kv` — एम्बेडेड LSM-Tree की-वैल्यू इंजन
- **भाषा**: C++20 / C
- **विवरण**: NVMe SSDs के लिए लिनक्स `io_uring` आधारित डायरेक्ट I/O स्टोरेज इंजन।

### 3. `packet-lens` — कर्नेल-स्पेस eBPF टेलीमेट्री एजेंट
- **भाषा**: C / Go
- **विवरण**: न्यूनतम CPU उपयोग के साथ XDP/TC हुक का उपयोग करके नेटवर्क स्थिति की निगरानी।

### 4. `flow-rpc` — ज़ीरो-कॉपी बाइनरी RPC फ्रेमवर्क
- **भाषा**: Rust / Go
- **विवरण**: यूनिक्स डोमेन सॉकेट्स पर फ्लैटबफ़र्स आधारित उच्च गति आरपीसी सिस्टम।
